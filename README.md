# Inside Her Head

Same street. Headphones on. What she hears, you hear.

- Live page: https://heylacey.github.io/inside-her-head/walk/ (a doorway that always opens the newest app.html, so updates show instantly)
- Wix custom element: Server URL `https://heylacey.github.io/inside-her-head/inside-her-head.js`, tag name `inside-her-head`
- Song clips are in `audio/`; `tools/make_clips.sh` remakes them (cut points and fuzz settings at the top).
